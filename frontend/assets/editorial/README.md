# DBgram editorial imagery

These original images were created with the built-in image-generation tool for
the October 2026 frontend redesign. They are illustrative marketing photographs,
not photographs or posts attributed to real users. No stock image service or
runtime image dependency is required.

- `coast.jpg`: the landing cover, 466,648 bytes.
- `architecture.jpg`: the landing feature, authentication panel, and editorial
  discovery card, 398,148 bytes.

Both originals were copied into this project and encoded as JPEG at quality 86
without resizing, cropping, or compositing. The original PNGs remain in Codex's
generated-image directory. JPEG copies reduce the combined transfer from 6.5 MB
to about 865 KB.

## Prompts used with the built-in tool

dramatic but serene high-angle view of a wild Mediterranean cove, chalk and

distant swimmer as scale. Cropped artfully, natural believable textures, analog

composition 4:5, full bleed. Gallery-worthy quiet everyday beauty. No purple, no
violet, no neon, no gold styling. No lettering, watermark, logos, typography,
border, mockup or UI. Save as a high-resolution photograph.

### Architecture

shadows. Candid analog medium-format architectural photograph, warm afternoon
light, richly detailed and understated. Vertical 4:5 full-bleed photographic
composition. Color palette muted rust, warm stone, deep botanical green. No
purple, violet, neon, gold styling. No people, text, watermarks, borders,
branding, graphic designs or UI. This is a photographic asset, not a website
